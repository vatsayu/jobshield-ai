# JobShield AI

AI-assisted cybersecurity platform for analyzing suspicious job postings,
recruiter messages, emails, screenshots, and recruitment documents.

## Core Principle

Analyze → Explain → Provide Evidence → Recommend Safe Action

## Project Status

Phase 1 — Repository and environment initialization.

## Planned Stack

- Frontend: Next.js, React, TypeScript, Tailwind CSS
- Backend: Python FastAPI
- Database: PostgreSQL
- AI: Structured LLM-based analysis
- Infrastructure: Docker Compose
- Testing: Pytest, API tests, security tests
